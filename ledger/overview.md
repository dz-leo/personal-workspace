## 二、分类体系（三通道 + 自定义分类）

参照你发来的微信记账本截图，分类重做成三通道：

- **支出**（20 项）：餐饮、交通、服饰、购物、服务、教育、娱乐、运动、生活缴费、旅行、宠物、医疗、保险、公益、发红包、转账、亲属卡、其他人情、退还、其他
- **入账**（9 项）：生意、工资、奖金、其他人情、收红包、收转账、商家转账、退款、其他
- **不计入收支**（3 项）：理财、借还款、其他 —— 房贷 / 车贷 / 信用卡还款 / 网贷本金走这里

**关键口径**：「不计入收支」天然不进任何统计（统计只查支出 / 入账两类），所以月供、还款不会污染预算、分类排行和热力图；只有利息 / 手续费算真消费。这正是之前问「房贷车贷怎么分」的答案。

**自定义分类**：表单里点「＋新增」，弹窗选图标 + 颜色 + 命名即可，新分类即时出现在对应通道下；自定义分类按钮右上角有 × 可删除（二次确认），删除后该分类的历史记录自动兜底归「其他」，不会丢账。

## 三、日 / 周 / 月 三种视图

**日视图** — 流水清单 + 收支结余三卡 + 与本月日均对比；右侧月度概览、今日分类/标签分布。

**周视图** — 7 天支出柱状图（虚线为周日均，超均值的柱子高亮），下方按天折叠分组，可点柱跳日。汇总含**环比上周**百分比。

**月视图** — 热力日历（5 级色阶：无/少/正常/偏高/超日均，按与当月日均的比值着色），点格子跳日。右侧：预算进度环、支出构成环形图、分类排行、近 6 个月趋势折线、商家 Top5、**可优化空间**（非必要+冲动占比，超 30% 给提示）。

## 四、本轮新增/修复的三个关键点

1. **「回到今天/本周/本月」快捷按钮**
   之前只能一格一格点箭头翻回去，翻到几个月前就很难回来。现在不在当前周期时，日期下方直接出现归位按钮，一步到位。

2. **「存并继续」金额清不掉（真 bug）**
   根因：`renderEditSheet()` 无条件先 `syncFormFromDOM()`，把旧 DOM 里的金额回读进新表单。这个 sync 是为「先输金额再选分类」加的，但主动重置时反而把已保存的金额又填了回来。
   修法：`renderEditSheet(noSync)`，重置场景传 `true` 跳过回读。

3. **测试断言写错**
   折线图用的是 `<path>` 而不是 `<polyline>`，断言选错元素导致误报失败。

## 五、资金账户与余额联动（S5）

账户从「名字清单」升级为完整对象（`id / 名称 / 类型 / 图标 / 颜色 / 初始余额 / 额度 / 账单日 / 计入净资产 / 归档`）。记录里 `account` / `toAccount` 存账户 **id**（与数据库一致）。

**余额不落库，实时派生**（前端与 MySQL 用同一套公式，永不漂移）：

```
余额 = 初始余额 + 入账 − 支出 − 转出 + 转入
净资产 = 总资产 − 总负债（信用类负数余额记为负债）
```

- 记一笔**支出/入账** → 对应账户余额即时增减；
- 记**转账**（不计入收支）→ 转出账户减、转入账户加；
- **余额调整**（不计入通道下的「余额调整」分类）→ 填真实余额一键对账，自动生成调整流水，不用手改余额；
- 删除账户 → 其历史记录自动归位到「其他」，不丢账。

**资产视图（「资产」Tab）**：顶部净资产三卡（总资产 / 总负债 / 净资产），下方按「资产 / 负债」分组列出每个账户实时余额，点账户可编辑/删除/对账。统计区为账户资金分布环形图。

## 六、远程同步与架构（S6）

```
业务代码  →  Storage.load() / Storage.save()  →  mode:'auto'
   │                                         ├─ http(s)：RemoteAdapter → GET/POST /api/db（server.py → MySQL）
   │                                         └─ file:// 或后端挂掉：LocalAdapter（浏览器 localStorage 镜像）
   └─ 写入先落本地镜像，再防抖同步远端；远端失败不丢数据
```

- `server.py` 是**全量快照**接口：`GET /api/db` 返回与前端结构一致的 JSON；`POST /api/db` 事务化全量落库（先清表再写，保证与前端一致）。
- 业务代码只认 `Storage` 抽象，换后端/云存储零改动。
- `auto` 模式：通过 http(s) 打开优先连 MySQL，双击 file:// 或后端没起来自动降级本地，两种用法都不卡死。
- 老数据兼容：`accounts` 曾是名字数组、`record.account` 存名字，首次加载自动迁移成对象 + id 映射。

**本地使用（纯前端）**：浏览器直接打开 `ledger/index.html`，数据存 localStorage。
**手机 / 局域网同步（连 MySQL）**：

```bash
cd ledger && python3 server.py --host 0.0.0.0 --port 8765
# 电脑：http://127.0.0.1:8765/   手机（同 WiFi）：http://<电脑内网IP>:8765/
```

首次会自动把示例数据写入 MySQL；之后每次记账自动同步。
**备份**：右上角「数据」→ 导出 JSON。
