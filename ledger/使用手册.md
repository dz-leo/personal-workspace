# 个人账本 — 使用手册

单文件网页账本，数据存在本机 MySQL 里，手机和电脑都能用。

- **数据位置**：本机 MySQL，库名 `ledger`（账号口令见 `~/.ledger.conf`，**不在代码里**）
- **网页地址**：`http://127.0.0.1:8765/`（本机）、`http://<电脑内网IP>:8765/`（手机，同一 WiFi）
- **文档版本**：2026-10-09

> 技术细节、架构和开发记录见 `overview.md`，日常使用看这份就够了。

---

## 〇、数据库配置在哪（先看这个）

代码和文档里**不写数据库口令**。口令存在你自己的电脑上：

```
~/.ledger.conf      权限 600，内容形如：
                    db_host=127.0.0.1
                    db_port=3306
                    db_user=root
                    db_password=你的MySQL密码
                    db_name=ledger
```

第一次使用（或换机器）生成它：

```bash
cd ledger
python3 server.py --init-conf     # 生成模板，权限自动设成 600
```

然后把 `db_password=` 填上，**保存后重启服务**（launchd 常驻的也要 `launchctl bootout` 再 `bootstrap`）。

读取优先级：**环境变量 `LEDGER_DB_*` > `~/.ledger.conf` > 内置默认值**。换密码时只改 `~/.ledger.conf` 即可，不用动代码、不用重新部署。

- 这个文件已在 `.gitignore` 里，不会被提交到仓库。
- 临时换端口/库名：`python3 server.py --db-name ledger_test --db-pass xxx`。
- 嫌口令太弱不安全：现在就 `mysqladmin -uroot -p` 改一个强口令，然后同步改 `~/.ledger.conf`（改完重启服务）。

## 一、启动与访问

### 方式一：开机自启（推荐，配一次终身省心）

在**你自己的终端**（不是别的环境）里执行一次：

```bash
lsof -nP -iTCP:8765 -sTCP:LISTEN -t | xargs kill -9 2>/dev/null
launchctl bootstrap gui/$UID ~/Library/LaunchAgents/com.dazhi.ledger.plist
brew services start mysql@8.0
```

- 第一行：清掉可能占着端口的旧进程
- 第二行：注册常驻服务，**开机自启、崩溃自动拉起**
- 第三行：让 MySQL 也开机自启（否则重启电脑后账本起来了却连不上库）

验证是否注册成功：

```bash
launchctl list | grep dazhi.ledger     # 有输出就是成功了
```

### 方式二：双击启动（临时用）

双击 `start.command`，自动起服务并打开浏览器，还会打印手机访问地址。

**限制**：那个终端窗口不能关，关了服务就停。

### 方式三：命令行

```bash
cd /Users/dazhi/Sites/tool/ledger
python3 server.py --host 0.0.0.0 --port 8765
```

**要有一个装了 PyMySQL 的 python**：`pip3 install pymysql` 即可。`start.command` 会自动在常见路径里找一个满足条件的解释器，找不到时按提示装；也可以手动指定 `LEDGER_PYTHON=/path/to/python bash start.command`。

> 已注册的 launchd 常驻服务里写死了某个 python 的绝对路径。如果以后换了解释器，记得同步改 `~/Library/LaunchAgents/com.dazhi.ledger.plist` 的 `ProgramArguments`。

### 手机访问

手机和电脑连同一个 WiFi，用 `http://<电脑内网IP>:8765/`。内网 IP 可以看 `start.command` 的输出，或执行：

```bash
ipconfig getifaddr en0
```

**第一次要在手机上手动输入一次令牌**（这是防局域网里别人打开你的账本）：

1. 服务启动时终端会打印一行带令牌的链接，例如
   `手机访问：  http://192.168.1.5:8765/?t=xxxxxxxx`
2. 手机浏览器打开**这一整条带 `?t=` 的链接**，令牌会自动存进这台设备
3. 之后「添加到主屏幕」，直接用 `http://192.168.1.5:8765/` 就行，不用再输

令牌也可以在 `~/.ledger.conf` 的 `api_token=` 处查看。换了手机、清了浏览器数据，就再输一次。

> **本机（`127.0.0.1`）访问不需要令牌** —— 只在这台电脑上用的时候不用被打扰。
> 手机 / 局域网访问必须带令牌，这是有意为之：公共 WiFi 下别人只要知道端口就能读你的账本。

手机打开后是移动 H5 版（底部 Tab 导航），建议「添加到主屏幕」，用起来跟 App 一样。

## 二、第一次使用：先把账建起来

现在库里是空的（7 个账户，余额都是 0）。**先给账户填真实余额，再开始记账**，否则余额会一直是负数。

### 1. 给账户设真实余额（对账）

1. 打开页面，点底部（或顶部）的**「资产」**
2. 点某个账户，比如「微信」
3. 点**「对账」**，填入你现在的真实余额
4. 保存

系统会自动生成一条「余额调整」流水把账做平，你不用自己算差额。

7 个账户：微信、支付宝、现金、银行卡、信用卡、余额宝、其他。用不上的可以在资产页删掉，也可以新增自己的账户。

### 2. 信用卡怎么设

信用卡是**负债账户**，余额为负表示欠多少钱。比如欠 3000，对账时填 `-3000`，或者直接记负债方向。

### 3. 开始记第一笔

点「记一笔」，选类型、填金额、选账户、选分类，保存。保存后对应账户余额**立即变化**。

## 三、日常怎么记

### 三种记录类型

| 类型 | 用途 | 影响余额 | 进统计 |
|---|---|---|---|
| **支出** | 花钱 | 账户减 | 是 |
| **入账** | 进钱 | 账户加 | 是 |
| **不计入收支** | 转账、还贷、理财 | 账户加减 | **否** |

### 转账怎么记

选「不计入收支」，分类选转账类，然后填**转出账户**和**转入账户**两个。保存后转出的减、转入的加，但**不算消费**，不会污染预算和分类排行。

典型场景：银行卡还信用卡、工资卡转余额宝、还花呗。

### 房贷 / 车贷 / 信用卡还款怎么记

**本金走「不计入收支 → 借还款」，利息走正常支出。**

原因：还款不是消费，只是钱从左口袋到右口袋。如果记成支出，你的月支出会虚高一倍，预算和排行全失真。只有利息、手续费才是真花钱。

### 自定义分类

记一笔时点分类区的「＋新增」，选图标、颜色、起个名，立刻可用。自定义分类右上角有 × 可删除（二次确认），删掉后历史记录自动归到「其他」，**不会丢账**。

### 编辑与删除

点流水记录即可编辑。删除需要二次确认。

## 五、资产视图

点「资产」看家底：

- 顶部三卡：**总资产 / 总负债 / 净资产**
- 下面按「资产」「负债」分组列出每个账户的实时余额
- 点账户可编辑、删除、对账
- 右侧是资金分布环形图

### 余额怎么算的（重要）

余额**不存数据库**，是实时算出来的，所以永远不会和实际流水对不上：

```
账户余额 = 初始余额 + 入账 - 支出 - 转出 + 转入
净资产   = 总资产 - 总负债（信用卡这类负余额记为负债）
```

**别直接改余额数字**——用「对账」功能，它会生成调整流水，账目有据可查。

## 八、数据安全（这节一定要看）

### 数据在哪

全部在本机 MySQL 的 `ledger` 库里。**网页只是界面，数据不在浏览器里。**

浏览器 localStorage 里有一份**镜像缓存**，是为了后端挂掉时应急用的。

### 警告：后端没起时会降级本地

如果你直接双击 `index.html` 用 `file://` 打开，或者后端服务没起来，账本会**自动降级到浏览器本地存储**。

这时你记的账**不会进 MySQL**，也和手机不同步。**判断方法**：看页面上的存储状态，显示「云端同步(MySQL)」才是对的，显示「本地存储(同步失败)」就是在降级模式。

### 备份（三种方式，任选）

1. **双击 `backup.command`** — 最简单，备份到 `backups/` 目录，自动清理 30 天前的
2. **命令行**（口令从配置读，不写死在命令里）：
   ```bash
   cd ledger && bash backup.command          # 推荐，同 1
   # 或手工导出（mysql 会提示输入密码）：
   mysqldump -uroot -p --default-character-set=utf8mb4 ledger > ~/ledger-backup-$(date +%F).sql
   ```
3. **应用内导出**：右上角「数据」→ 导出 JSON（适合搬家、换设备）

建议每周备份一次，或者每次大额记账后顺手点一下。

### 恢复

```bash
gunzip -c backups/备份文件.sql.gz | mysql -uroot -p ledger   # -p 之后回车再输密码
```

### 危险：ledger-init.sql 会清空数据

`ledger-init.sql` 里有 `DROP TABLE` 语句，**执行它会删光所有表，数据全没**。

只在这些情况用：换电脑重建库、表结构损坏需要重建。**执行前必须先备份。**

文件顶部已经加了醒目警告，但这里再说一遍。

## 九、常见问题

### 打不开 http://127.0.0.1:8765/

后端服务没起。按顺序排查：

```bash
lsof -nP -iTCP:8765 -sTCP:LISTEN     # 有没有输出？没有就是服务没起
mysqladmin -uroot -p status          # MySQL 活着吗（回车后输密码）
cat ~/.ledger.conf                   # 配置读到了吗（db_password 应该有值）
```

解决：按「方式一」注册常驻服务，或双击 `start.command`。

### 端口不是 5000 吗

**是 8765，不是 5000。** 5000 被 macOS 的 Control Center（AirPlay）占了，用不了。

### 余额对不上

八成是账户初始余额没设。去「资产」页对账，把真实余额填进去。

或者检查有没有把还款记成了支出（见第三节）。

### 手机连不上

1. 手机和电脑同一 WiFi
2. 后端要用 `--host 0.0.0.0` 启动（脚本里已经是了）
3. 用内网 IP，不是 127.0.0.1
4. macOS 防火墙可能拦截，首次访问时允许一下

### 改了数据但手机没变

手机刷新一下。数据是全量同步的，写入有 0.5 秒防抖，稍等再刷。

### 想清空重来

应用内「数据」→「清空全部」，需要输入「清空」二字确认。

cd /Users/dazhi/Sites/tool/ledger

# 看账户余额（MySQL 直接查）
mysql -uroot -p ledger -e "SELECT id,name,init_balance FROM accounts"
